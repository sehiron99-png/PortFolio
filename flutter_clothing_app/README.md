# Flutter Clothing App (의류 추천 애플리케이션)

`android/` : 안드로이드 앱 빌드 및 구동을 위한 네이티브 파일이 저장되는 폴더

`ios/` : iOS 앱 빌드 및 구동을 위한 네이티브 파일이 저장되는 폴더

`lib/` : 앱의 실제 Dart 코드(UI, 로직, 상태 관리 등)가 위치하는 핵심 개발 폴더

`test/` : 단위 테스트 및 UI 테스트 코드가 위치하는 폴더

`analysis_options.yaml` : Dart 코드의 정적 분석 규칙 및 린트 규칙을 정의하여 코드 스타일과 품질을 관리하는 설정 파일

`pubspec.yaml` : 프로젝트의 이름, 설명, 앱 버전 및 외부 패키지와 패키지 자원을 관리하는 핵심 설정 파일

`pubspec.lock` : 설치된 외부 패키지의 정확한 버전을 고정 및 기록하여 개발 환경 간 동일한 버전을 유지하게 해주는 파일

`flutter_clothing_app.iml` : IntelliJ / Android Studio IDE 환경에서 프로젝트 구조를 인식하기 위해 자동 생성되는 설정 파일
