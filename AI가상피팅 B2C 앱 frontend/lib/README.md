# lib

- **`models/`**: 앱에서 사용되는 데이터 구조를 정의하는 모델 클래스 집합
- **`providers/`**: Provider 라이브러리를 활용하여 상태 관리 및 백엔드 API와의 통신/비즈니스 로직을 처리하는 클래스 집합
- **`screens/`**: UI의 각 화면 페이지(메인 화면, 가상 피팅 화면, 마이페이지, 상품 상세 페이지 등)를 구성하는 스크린 위젯 집합
- **`theme/`**: 앱 전반에 적용되는 색상 팔레트, 폰트 스타일, 버튼 디자인 등 UI 테마 설정을 관리하는 파일 집합
- **`widgets/`**: 여러 화면에서 재사용되는 공통 UI 컴포넌트 집합
- **`main.dart`**: Flutter 애플리케이션의 엔트리 포인트로, 초기 설정 및 Provider/테마/라우팅 등을 등록하는 핵심 파일
